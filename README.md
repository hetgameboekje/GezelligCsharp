# GezelligCsharp — Pac-Man WinForms Game

A school project (VISTA project methodology) built to create a game using a Windows Forms (WinForms) application in C#. The project is a Pac-Man–style game ("pcman game").

## About

This repository was created as a school assignment with the goal of designing and building a small game as a desktop WinForms application in C#. The game follows the classic Pac-Man concept.

## Project structure

- `Main/` — the main WinForms application project (game logic and UI).
- `MainTest/` — unit tests for the main project.
- `pcman game/` — Pac-Man game assets and/or related project files.
- `GezelligC-.csproj` — the .NET project file.
- `bin/`, `obj/` — build output folders (generated by the .NET build process).

## Requirements

- .NET 7.0 SDK
- Windows (WinForms applications run on Windows)

## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/hetgameboekje/GezelligCsharp.git
   ```
2. Open the solution/project in Visual Studio (or another .NET-compatible IDE).
3. Restore dependencies and build:
   ```bash
   dotnet build
   ```
4. Run the application:
   ```bash
   dotnet run --project Main
   ```

## Context

This project was made for school, following the VISTA project approach, to practice building a functional game with a WinForms front-end in C#.
